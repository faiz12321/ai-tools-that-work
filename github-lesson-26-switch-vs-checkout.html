git: switch -c vs checkout -b (what's the difference?)

Short answer

There is no difference in the result: git switch -c name and git checkout -b name both create a branch at the current commit and move you to it. git switch is the modern branch-only command added in git 2.23, when checkout's two jobs were split into switch (branches) and restore (files). And git switch - jumps back to the branch you were just on.

Common mistakes with switch and checkout

  1. Believing the two spellings do different things. switch -c and checkout -b are the same operation. Pick the one your team reads best and move on.
  2. Reaching for checkout -- file out of habit. The modern spelling is git restore. Both discard uncommitted changes permanently - that is why the split exists: switch can never eat your edits by accident.
  3. Not knowing git switch - exists. Like cd -, a single dash means "the branch I was just on". It is the fastest way to bounce between two branches.
  4. Assuming checkout is deprecated. It is not. Old scripts, old docs and older gits all rely on it. switch and restore are additions, not removals - but they need git 2.23 or newer.

Frequently asked questions

What is the difference between git switch -c and git checkout -b?

None in the result. Both create a new branch at the current commit and move you to it. git switch is the newer, branch-only spelling added in git 2.23 (2019); checkout -b still works and is not deprecated.

Why does git have both switch and checkout?

git checkout grew two unrelated jobs: switching branches and restoring files. Git 2.23 split them into two focused commands: git switch moves between branches, git restore restores files. checkout keeps both behaviors for compatibility.

How do I go back to the branch I was just on?

git switch - (a single dash) jumps to the previously checked-out branch, like cd - in a shell. git checkout - does the same.

Can git switch restore files like checkout does?

No - that is the point of the split. Use git restore <file> to discard uncommitted changes or unstage files. Be careful: git restore and git checkout -- <file> throw away uncommitted work permanently.

Which git version has git switch?

git switch and git restore were added in git 2.23 (August 2019). Check your version with git --version. On older versions, use git checkout -b.
