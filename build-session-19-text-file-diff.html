How to see what changed between two text files

Short answer

You have an old and a new version of a text file and want to know what changed. This lesson builds a small read-only Python tool that compares them line by line with Python's difflib module, counts the lines added and removed and shows the first 20 lines of the difference in the usual plus and minus layout. The tool has no code that writes to a file. Line endings are not compared.

Follow along and build it step by step. You add each file yourself, run each command, and see the real recorded result.

Common mistakes

  1. Comparing only the number of lines. The first version in this lesson counts lines. A line that was replaced leaves the count unchanged, and even a changed count does not say what changed.
  2. Expecting a changed line to count once. This tool shows a changed line as one line removed and one added, so a single edit gives one of each.
  3. Assuming spaces at the end of a line do not matter. They are compared. A line with a space added at the end is reported as a difference even though it looks the same.
  4. Treating "the text is the same" as "the files are identical". The tool ignores line endings and a missing last line ending. Files with different bytes can be reported as the same text.

Frequently asked questions

How do I see what changed between two text files?

Read both into lists of lines and pass them to the difflib module's unified_diff function. This lesson builds a small tool around that.

Will this change either file?

No. The tool only reads them. A test checks that both practice files keep the same bytes and modified time.

What do the plus and minus signs mean?

A line starting with a minus is only in the old file. A line starting with a plus is only in the new file. A line starting with a space is shown for context.

Why does it say the text is the same when my files are different?

Line endings, such as Windows or Linux style, and a missing last line ending are not compared. The practice file with Windows line endings is reported as the same text as the old menu.

Why does it show only 20 lines?

To keep the report short. The counts cover the whole difference, and the tool says how many lines were not shown.

Does it work on any file?

It reads text saved as UTF-8. Anything else is reported as not valid UTF-8, and it has only been tried on small made-up files.
