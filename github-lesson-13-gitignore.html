git: how do I make git ignore files? (.gitignore)

Short answer

Write a pattern like *.log in a file named .gitignore and untracked files matching it vanish from git status. But .gitignore only works on files git has never tracked: for an already-committed file, run git rm --cached filename to untrack it while keeping it on disk, then commit.

Common mistakes with .gitignore

  1. Expecting .gitignore to untrack committed files. It only affects files git has never tracked. The fix for a committed file is git rm --cached, then commit.
  2. Deleting the file instead of ignoring it. debug.log will come back at the next run. Ignoring the pattern solves it forever.
  3. Forgetting to commit .gitignore. Uncommitted, the rules exist only on your machine; teammates still see the noise.
  4. Using git rm when you meant git rm --cached. Plain rm deletes the real file from disk. --cached removes it only from git's index.
  5. Thinking untracking erases history. Old commits still contain the file. If it held a real password, change the password.

Frequently asked questions

How do I make git ignore a file?

Create a file named .gitignore in the repo and write the file name or a pattern like *.log in it. Untracked files matching the pattern disappear from git status and cannot be added by accident.

Why is my file still tracked even though it is in .gitignore?

.gitignore only affects files git does not track yet. A file that was already committed keeps being tracked. Run git rm --cached filename to untrack it while keeping it on disk, then commit.

How do I check why a file is ignored?

Run git check-ignore filename. If the file is ignored, the command prints its name back; silence means it is not ignored.

Does git rm --cached delete my file?

No. --cached removes the file only from git's index, the staged copy. The real file stays on your disk. Plain git rm would delete both.

Should .gitignore itself be committed?

Yes. Committing it shares the ignore rules with everyone who clones the repo, so the whole team stops seeing the same noise files.

Can I ignore a whole folder?

Yes, write the folder name with a trailing slash, like build/. Every file under it is ignored.
