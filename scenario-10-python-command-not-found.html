python: command not found. How do I fix it?

Short answer

command not found means no program by that name exists on this machine. On Ubuntu, Python 3 is usually installed as python3, not python. Check with command -v python3, then run the same command with python3. If python3 is also missing, install it with sudo apt install python3.

Common mistakes with command not found

  1. Reinstalling before checking. A second Python can shadow or conflict with the one already there. This machine already had Python 3, under the name python3.
  2. Editing PATH or adding aliases from a forum without reading them. One wrong line in .bashrc can break every new terminal you open.
  3. Assuming the script is broken. command not found is about the program name, so the file was never even read.
  4. Renaming or moving the script. Its name and place were never the problem.
  5. Linking python to python3 on a shared machine. python-is-python3 exists for your own machine, but it changes what every program that says python receives.

Frequently asked questions

Why does Ubuntu have python3 but no python?

Since Ubuntu 20.04 the plain name python is not installed by default; Python 3 comes as python3. On your own machine, the python-is-python3 package makes python point at python3.

What does exit status 127 mean?

The command was not found: the shell searched its known locations and no program by that name exists. Compare 126: found, but it could not be run.

What does command -v do?

It prints how the shell would resolve a name: a path, an alias or a builtin. It prints nothing and fails when the name does not exist. which is similar; command -v is a shell builtin.

Is it safe to make python point to python3?

On your own machine, the python-is-python3 package exists for exactly this, but it changes what every program that says python receives. On shared or work machines, prefer typing python3.

The guide's first line says #!/usr/bin/env python. Same fix?

Run it as python3 script.py, or change that first line to python3 if the script is yours. The first line only matters when you run the script directly with ./script.py.

python3 is also missing. Now what?

Then Python really is not installed. On Ubuntu, sudo apt install python3 installs it. Only install packages on a machine you own or have permission to change.
