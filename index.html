  • git: You are in 'detached HEAD' state. How do I fix it?

  • git: error: pathspec did not match. How do I fix it?

    Git. The name does not exist as a branch, tag or file: list with git branch, then switch to it or create it with git switch -c. An 8-step practice with real recorded output.

  • git: how do I undo git add?

    Git. Unstage without losing work: git restore --staged takes a file off the commit list and keeps it on disk. An 8-step practice with real recorded output.

  • git: fatal: refusing to merge unrelated histories?

    Git. Two branches with no shared commit: when they truly belong together, git merge branch --allow-unrelated-histories joins them. An 8-step practice with real recorded output.

  • git: how do I save unfinished work and get it back?

    Git. git stash shelves uncommitted changes for a clean tree; git stash pop brings them back and clears the shelf. An 8-step practice with real recorded output.

  • git: how do I create, switch, and delete branches?

    Git. git branch makes a label, git switch moves to it, git branch -d deletes only after git checks it is safe; -D forces. An 8-step practice with real recorded output.
