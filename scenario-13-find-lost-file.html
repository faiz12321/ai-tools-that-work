I lost a file on Linux. How do I find it?

Short answer

Search your home folder three ways. By name: find ~ -iname "*report*", where -iname ignores capitalization and the stars allow words around the part you remember. By the words inside: grep -rl "Q3 revenue" ~ prints only the files containing that phrase. By when it changed: find ~ -type f -mtime -1 lists files touched in the last day. Then open the match with cat to confirm it is the right file.

Common mistakes when searching for a file

  1. Typing the star pattern without quotes. The shell expands *report* itself before find ever sees it. Always quote the pattern: find ~ -iname "*report*".
  2. Using -name when the capitalization is a guess. -name is case-sensitive, so report and Report are different to it. -iname matches any capitalization.
  3. Searching the whole disk first. find / crawls everything and floods you with Permission denied lines. Start at ~; it is almost always where the file is.
  4. Giving up after one exact-name search. No output is not an error; it is a wrong guess. Loosen the pattern with stars, or switch to searching the contents with grep -rl.
  5. Forgetting that find matches folders too. *report* also matched the reports directory itself. Add -type f when you want files only.

Frequently asked questions

I saved a file on Linux and forgot where. How do I find it?

Search your home folder by name first: find ~ -iname "*part-of-name*". The ~ means your home folder, -iname ignores capitalization, and the stars match any text around the part you remember.

How do I find a file when I only know part of its name?

find ~ -iname "*part*" finds every file and folder whose name contains that part, with any capitalization. Quote the pattern so the shell does not expand the star.

How do I find a file by the words inside it?

grep -rl "the phrase" ~ searches inside every file under your home folder and prints only the names of files that contain the phrase.

How do I find files I changed recently?

find ~ -type f -mtime -1 lists files modified in the last 24 hours. Use -2 for the last two days or -7 for the last week.

Why did find print a folder, not just my file?

find matches every entry whose name fits the pattern, including directories. Add -type f to list files only, or -type d for folders only.

What is the difference between -name and -iname?

-name is case-sensitive, so Report and report are different names to it. -iname matches any capitalization. When you are not sure of the exact name, use -iname with a partial pattern.
