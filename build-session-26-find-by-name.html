How to find every file whose name matches a pattern

Short answer

You remember part of a file name, not where the file is. This lesson builds a small read-only Python tool that lists every file inside a folder whose name matches a pattern: a star stands for any run of characters and a question mark for exactly one. Matching ignores letter case on every system, so "*.jpg" also finds dog.JPG. The tool has no code that changes, moves or deletes anything, and it looks only at names, never inside files.

Common mistakes

  1. Searching for a pattern as plain text. A simple text search treats *.jpg as four literal characters and finds nothing. The star and question mark only work as wildcards when the tool understands patterns.
  2. Assuming letter case matters the same everywhere. Windows ignores case in file names and Linux usually does not. This tool ignores case everywhere, so the same pattern finds the same files on any system.
  3. Thinking a match proves you found everything. Folders the tool cannot read are skipped, and only names are matched. A file with an unexpected name will not appear.

Frequently asked questions

What do the star and question mark mean?

A star stands for any run of characters, including none. A question mark stands for exactly one character. These wildcards come from Python's fnmatch module.

Why did *.jpg also find dog.JPG?

The tool lowercases both the file name and the pattern before matching, so letter case never matters. That matches how Windows treats file names, and keeps results the same on Mac and Linux.

Will this change or delete anything?

No. The tool only reads the folder. A test checks that the source has no code that writes, and another checks that a folder, including its files' changed times, is exactly the same after a run.

Does it search inside files?

No. Only file names are matched, never contents, and never folder names.

Why do the paths not start with a drive letter?

Paths are printed relative to the folder you search, with forward slashes, so the same report reads the same on Windows, Mac and Linux.
