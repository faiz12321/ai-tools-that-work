About the recording

The commands were run on a small Linux lab (Ubuntu 22.04, Node.js v22.23.3, Python 3.10.12, iproute2 5.15.0, lsof 4.93.2, procps-ng 3.3.17, curl 7.81.0) in its own process and network space, so the lists show only the lab's programs. A script ran every command in the order of each game state and captured its output and exit code. The whole recording was run twice from scratch and the two runs matched, except for one command (lsof -i :8080) whose output includes a socket number that changes each run. That command is not offered in this game. Numbers such as process IDs came out the same in both runs and are shown as recorded.

The shop, its folders and the reports server are made up for this lesson. Game notes (yellow, blue and red boxes) are authored text, not captured output. Tested only in Chrome.
