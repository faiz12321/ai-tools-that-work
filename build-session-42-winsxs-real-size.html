Measure the Windows component store with DISM analysis

Short answer

Windows can share component-store files through hard links, so adding file lengths is not the same as measuring extra disk use. DISM analysis reports a hard-link-aware actual size, but that number includes files shared with Windows. It is not the amount you can delete. This lesson captures an analysis and builds a small parser. It never asks for cleanup.

Follow along and build it step by step. You run each command and see the real recorded result.

Common mistakes

  1. Calling analysis perfectly read-only. Analysis is not cleanup, but it writes reports/logs and Windows may update servicing state.
  2. Treating Actual Size as freeable space. It includes files shared with Windows. Backups plus cache are reported overhead categories, not a promise they can all be deleted.
  3. Hand-deleting WinSxS. Use Microsoft guidance for servicing decisions; this lesson does not run any cleanup command.

Frequently asked questions

Does this delete anything?

No cleanup or deletion command is requested. The capture creates a results folder and logs; Windows can also write servicing logs/state. It is not a machine snapshot.

Why administrator rights?

Microsoft directs DISM component-store analysis from an administrator terminal. A non-admin capture stops before creating results.

Do Linux tests run DISM?

No. Ubuntu runs only the Python parser tests with synthetic reports. Actual capture is Windows-only.

Why are my numbers different?

They depend on the machine, servicing state and time. There is no guaranteed ordering, cleanup recommendation or reclaimable amount.

Why might the parser refuse?

It requires the expected English field names, size fields exactly once and a successful completion line, and a small ordinary UTF-8 report. Missing/localized fields, duplicated size fields and unsafe inputs refuse. It does not authenticate report origin.

Can I run capture again?

Not in the same lesson folder: existing results paths refuse. Keep the first reports and use another NEW empty lesson folder if you need another analysis. No automatic reset or cleanup.
