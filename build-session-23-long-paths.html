How to find file paths that are too long for many Windows programs

Short answer

Windows has a traditional limit: a full path can be 260 characters at most. Newer Windows lets each program opt in to longer paths, but the tool cannot tell which of your programs did. This lesson builds a small read-only Python tool that measures the full path of every file and folder and lists the ones at or past 260 characters. It counts characters the way Windows does, where an emoji counts as two. The tool has no code that changes, moves or deletes anything. A clean report only means no path reached 260 characters where you looked.

Common mistakes

  1. Measuring only the part you typed. The first version in this lesson reports that sample is 6 characters. Windows counts the whole path from the drive, and that full count is what hits the limit.
  2. Assuming a new Windows has no limit. Longer paths are something each program must opt in to. The tool cannot tell which of your programs did, so it lists everything at or past the old limit.
  3. Counting characters the way Python does. Windows counts UTF-16 units. Most characters count as one, but an emoji counts as two. The tool counts the Windows way.
  4. Treating a clean report as a guarantee. Only the character count is checked. A program can still dislike a name or a file for another reason.

Frequently asked questions

What is the 260 character limit?

Microsoft calls it MAX_PATH: the Windows API traditionally allows a full path of 260 characters at most, counting from the drive letter. Newer Windows versions let each program opt in to longer paths.

Will this change my files?

No. The tool only reads the folder. Tests check that nothing is changed or created.

Why is the count bigger than the folder name I see?

The count is of the full path, starting at the drive or root, because that is what Windows measures. A file called notes.txt can still have a 300 character full path.

Why does an emoji count as two characters?

Windows counts UTF-16 units. Most everyday characters are one unit, but emoji and some other rare characters are two. The tool counts the same way Windows does.

My Windows is new. Is the limit gone?

Not for every program. Newer Windows lets each program opt in to longer paths, and the tool cannot tell which of your programs did. That is why it lists everything at or past the old limit.

Does a clean report mean everything will work?

No. It only means no path reached 260 characters where you looked. Programs can also reject names for other reasons, and folders the tool could not read are only mentioned.
