git: find who committed what, when (git log --author --since)

Short answer

Filter history instead of reading all of it: git log --author="Ada" --oneline for one person's commits, git log --since="2026-09-01" --until="2026-09-30" for a date window, and git shortlog -sn for commit counts per author. Filters stack - every one you add narrows the list further (AND, not OR).

Common mistakes with git log filters

  1. Reading the whole log by eye. Filters exist so you do not have to. --author, --since and --until get the answer in one line, and they compose.
  2. Assuming --author needs an exact name. It is a pattern matched against "Name <email>" - "Ada" matches, but so would "Adams". Quote precisely, or use the email, when names collide.
  3. Expecting filters to OR. --author and --since together mean BOTH must hold. If a commit you expected is missing, one of the filters excluded it - widen one at a time.
  4. Thinking --since looks at the author date. It filters on the commit date. They are usually identical, but a rebase or amend keeps the old author date while refreshing the commit date - a commit can be "from August" and still appear after --since yesterday.

Frequently asked questions

How do I see git commits by one author?

git log --author="Ada" --oneline lists only commits whose author matches. The value is a pattern matched against the author name and email, so part of a name or an email works too.

How do I list git commits between two dates?

git log --since="2026-09-01" --until="2026-09-30" --oneline shows only commits in that window. The bounds compare against the commit date, and plain YYYY-MM-DD dates are the reliable format.

What does git shortlog -sn do?

It summarizes history by author: -s gives a commit count per author and -n sorts by that count, highest first. In a terminal, plain git shortlog -sn uses HEAD; in scripts pass the branch explicitly, like git shortlog -sn HEAD.

Do --author and --since combine as AND or OR?

AND. git log --author="Ada" --since="2026-09-01" shows commits that are both by Ada and after that date. Every filter you add narrows the list further.

How do I control what each git log line shows?

Use --format with placeholders, for example git log --format="%h %ad %an: %s" --date=short prints short hash, date, author name and subject per line. --date=short renders dates as YYYY-MM-DD.
