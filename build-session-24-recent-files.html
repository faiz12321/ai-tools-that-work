How to find the files that changed in the last few days

Short answer

Windows shows a "Date modified" for every file. This lesson builds a small read-only Python tool that lists the files in a folder changed inside a window you pick, seven days by default, newest first. A day means 24 hours, not a calendar date, so a file written yesterday at 23:00 is only eight hours old at 07:00 the next morning. The tool has no code that changes, moves or deletes anything. It reads only the changed times, not the contents.

Follow along and build it step by step. You add each file yourself, run each command, and see the real recorded result.

Common mistakes

  1. Comparing calendar dates. The first version in this lesson calls a file written yesterday at 23:59 one day old, and shows the future-dated file as minus two. Whole dates drop the clock, so answers jump at midnight.
  2. Thinking "Date modified" means the file was created. It is the last time the contents were written. Copying a file can give the copy a new time, so the report is about changes, not age.
  3. Forgetting part days. The tool rounds down: 2 days and 3 hours shows as "2 days ago". Under a day shows as "today".
  4. Treating the report as contents. The tool reads changed times only. It says nothing about what is inside a file.

Frequently asked questions

What is "Date modified"?

The last time a file's contents were written. Python's os documentation calls it st_mtime, the time of the most recent content modification, measured in seconds.

Will this change my files?

No. The tool only reads the folder and its changed times. Tests check that nothing is changed or created, including the changed times themselves.

Why does a day mean 24 hours here?

Because the tool compares times in seconds. A calendar date drops the clock, so a file written one minute before midnight would count as a day old one minute later.

Why is a file shown as "a future date"?

Its changed time is ahead of your clock. That happens, for example, after a wrong clock or a file from a machine in another time zone. The tool says so instead of guessing.

Can copying a file fool the report?

Yes. A fresh copy can carry a new changed time. The report is about when contents were last written, as the system recorded it, not about who did what.

Does the tool read my files' contents?

No. It asks the system for each file's changed time and never opens the files.
