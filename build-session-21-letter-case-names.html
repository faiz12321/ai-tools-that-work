How to find file names that differ only in letter case

Short answer

A typical case-sensitive Linux folder can hold Report.docx and report.DOCX as two different files. Windows treats them as the same name by default, so two such files can clash in a Windows folder. This lesson builds a small read-only Python tool that finds names that differ only in letter case, in a list or inside a folder. The tool has no code that renames or creates a file. A clean report does not mean the names will work on every system.

Common mistakes

  1. Comparing only neighbouring names. The first version in this lesson compares each name with the one before it. Names that differ only in case are often far apart in a list, so it finds none.
  2. Comparing names from different folders. Only names in the same folder collide. docs/a.txt and other/A.txt can sit together without a problem, so the tool compares names inside one folder.
  3. Counting the same name twice. A name written twice exactly is not a case problem. The tool reports names that differ in case, not repeated lines.
  4. Treating a clean report as a guarantee. The tool only knows about letter case. A name can still break other Windows rules, and a file system uses its own letter table.

Frequently asked questions

Why do names that differ only in case matter?

Microsoft's page says Windows treats FOO.txt and foo.txt as the same name by default, and Linux treats them as different. Two such files can exist on Linux and then clash when copied to a Windows folder.

Will this rename or delete my files?

No. The tool only reads names. Tests check that nothing is created or changed in the practice folder.

Why are the clashing practice names only in a list?

By default Windows treats two names that differ only in case as the same name, so the lesson keeps them as text. The folder practice uses names that do not clash.

Can a Windows folder be set to tell them apart?

Microsoft's page says a folder can be marked case sensitive, which needs administrator rights and can break programs that assume otherwise. This lesson does not change any setting.

Does a clean report mean the names are safe everywhere?

No. It only means no two names differ in letter case alone. Other rules, such as forbidden characters, are not checked here.

Why are some names printed with backslash codes?

Special characters are written as escapes so the report shows on any console. For example a letter e with an accent is written as \xe9.
