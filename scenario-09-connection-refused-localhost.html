Connection refused on localhost. How do I fix it?

Short answer

Connection refused means the computer answered, but nothing is listening on that port. On your own machine, check with ss -ltn 'sport = :3000'. If nothing shows, the service was never started: start it, run ss again, then retry. It is not a curl problem, and on localhost it is usually not a firewall.

Common mistakes with connection refused

  1. Blaming the firewall first. On your own machine, refused usually means nothing is listening. A blocked connection more often hangs until it times out instead of answering at once.
  2. Reinstalling curl or switching tools. The (7) in the message comes from the operating system, so every tool reports the same refusal.
  3. Retrying in a loop. curl cannot start the service for you. Retry after something is listening, not before.
  4. Mixing up refused and could not resolve. Could not resolve host means the name lookup failed. Refused means the machine answered and the port is closed.
  5. Forgetting the demo server. python3 -m http.server shares the files in its folder. Stop it when you are done: kill %1 stops the background job in that terminal.

Frequently asked questions

What does Connection refused mean?

The computer you reached answered actively: nothing is listening on that port. It differs from a timeout (no answer at all) and from could not resolve host (the name lookup failed).

What does curl exit status 7 mean?

Failed to connect to the server. It is the same 7 as in the (7) at the start of the error message.

What does ss -ltn 'sport = :3000' do?

It lists listening TCP sockets with numeric port numbers, filtered to port 3000. No rows means nothing listens there. On older systems, netstat -ltn does a similar job.

The service is running but I still get refused. Why?

Check the address and port it actually listens on. A service can listen only on 127.0.0.1, only on IPv6, or on a different port. ss -ltn shows the exact listening address.

Is python3 -m http.server safe to use?

It is a small demo file server that comes with Python for quick tests, and Python's own documentation says it is not meant for production use. Serve only practice folders and stop it when you are done.

What if the refused connection is to another computer?

It means that machine answered and nothing listens on that port there, or a device in between rejects the connection. On that machine, check whether the service runs and which address it listens on.
