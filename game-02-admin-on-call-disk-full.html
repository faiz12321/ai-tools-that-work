About the recording

The commands were run on a small Linux lab (Ubuntu 22.04, GNU coreutils and findutils, df and du from the same system) in its own process and mount space. The shop's data disk is a 40 MB lab disk mounted at /srv/data, filled by a script until writes failed. A script ran every command in order for each game state and captured its output and exit code. The whole recording was run twice from scratch and the two runs matched exactly. The plain df -h command is not offered, because on the lab it would list the lab host's own disks.

The shop, its folders and the log lines are made up for this lesson. Sizes are as recorded on a lab disk. Game notes (yellow, blue and red boxes) are authored text, not captured output. Tested only in Chrome.
