tar says "not in gzip format". How do I fix it?

Short answer

Check the actual file type with file backup.tar.gz. If it says POSIX tar archive, it is a plain tar despite its name. List it with tar -tf backup.tar.gz, create a new empty destination, then extract without forcing gzip: tar -xf backup.tar.gz -C restored. If file says HTML document, stop and check the download source instead.

Common mistakes

  1. Trusting the suffix. A file named .gz need not contain gzip data. Inspect it with file.
  2. Adding sudo. Extra permissions do not repair a format mismatch.
  3. Removing -z for every error. It works for this plain tar, not for HTML or damaged input.
  4. Extracting over your work. Use a new empty destination. Do not reuse one with valuable files.
  5. Calling a listing an integrity check. A list of names does not authenticate the archive or verify every byte.

Frequently asked questions

Why does tar say not in gzip format?

You requested gzip decompression, but gzip did not recognize the input as gzip data. It may be a plain tar with the wrong suffix, an HTML download page, another format, or damaged data. Start with file backup.tar.gz.

Can I just remove -z?

In this lab, yes: file identifies a plain POSIX tar archive. Use tar -tf to inspect it, then tar -xf to extract. Removing -z will not turn HTML or damaged bytes into a tar archive.

What does -C restored do?

It tells tar to use restored as the extraction directory. Create a new empty directory first. Do not reuse a destination that holds files you need.

Does renaming .tar.gz to .tar fix the file?

Renaming changes only the name, not the bytes. It can make a mislabeled plain tar less confusing, but is not needed for the extraction shown here.

Why not use sudo?

This is a format error, not a permission error. Root privileges are unnecessary for extracting your own trusted archive into a directory you own.

Does tar -tf prove an archive is safe?

No. A listing helps you inspect the intended contents, but does not establish trust, authenticity, or complete data integrity. Do not run extracted programs just because listing succeeded.
